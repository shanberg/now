# Specifications

## Now

- Based on a markdown file
- Can be edited in a text editor
- Full support in a CLI and TUI

## Raycast Extension

- Supports multiple now files
- Watches the active application to switch between now files
- Previews the result of a mutation in the detail view
- Provides a list of actions to perform on the focus
- Allows manually pinning/unpinning the current now file
- Allows manually switching the current now file

## Watcher

- Respond as fast as possible.
- On switching to an app with a registered Now file, show the appropriate focus
- On switching to an app without a registered Now file, show the global focus

### Menubar component

- Shows the current focus in the menu bar
- Allows completing the focus
- Allows opening the focus list
- Allows pinning/unpinning the current now file
